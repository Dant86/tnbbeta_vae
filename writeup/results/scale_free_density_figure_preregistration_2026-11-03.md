## Purpose and the honest framing the figure must carry

Goal: a figure that illustrates the pre-registered pooled finding (H1 of the metric-first study: within-family Spearman +0.462 of TNBBeta's truth-KL advantage vs log nominal degree, 200 fresh configs, one-sided permutation p = 0.0001) with `scale_free` graphs at three mean-degree levels, **while showing the losses**. What the caption must state (generated into the figure subtitle, not left to later judgement):

1. `scale_free` was chosen for the figure *for visibility, after looking at per-family slopes* (`per_family_slope_check_2026-11-03.md`): a selection effect, so the family slope (+0.47) is biased upward and its interval spans 0. The pooled panel is the unbiased evidence.
2. Degree heterogeneity is NOT varied: the data do not support a heterogeneity effect (CV given degree not detected in any family).
3. The bars come from full-size runs (n = 600), not from the drawn 36-node graphs; the drawings are schematic, the drawn mean degree is rescaled (see below).
4. The bars are a new, pre-registered 3-level experiment (32 fresh draws per level); the pooled scatter is cached fresh-stage data trained with the *library* (biased) vMF sampler, whereas the new bars use the exact one (the sampler audit found no detectable effect on the comparison).

## Design

**Configs (three, differing only in mean degree).** `scale_free` of `tnbbeta_vae.data.graph_space` (Chung-Lu with mean-one Pareto weights; tail index `1.4 + 8/(1 + contrast)`), `num_nodes = 600` (the median-ish node count of the 20 fresh scale_free configs, 300-1050), `contrast = 13.0` (tail index 1.97; median of the fresh scale_free contrasts is 13.7, range 3.6-254), `features = "none"` (identity), `heterogeneity = "none"`, `num_groups = 2` (ignored by this family). `mean_degree` = **6 (LOW), 15 (MED), 35 (HIGH)** (fresh scale_free nominal degrees range 4.4-33.3; the pooled panel spans 4-40). The contrast is held fixed rather than re-calibrated to a common oracle AUC because calibration would change the tail index (heterogeneity) with the level, which is exactly what must NOT be varied. Generator check done before freezing (no model trained; 8 draws per level, n = 600): realised mean degree 6.0 / 14.9 / 34.9; expected-degree CV 1.03 / 0.98 / 0.88; expected oracle AUC 0.729 / 0.731 / 0.735; clipped-pair fraction about 0 / 0 / 0.002. So density is varied with the tail exponent, node count and oracle AUC essentially fixed; the CV falls slightly (about -0.15 from LOW to HIGH) because clipping at probability 1 trims the hubs. This residual CV drift is a known, accepted confound and is reported per level (realised degree, CV, clustering, oracle AUC).

**Draws.** **32 independent draws per level** (graph, edge split, init all drawn from the draw's seed `60_000_000 + 1000 * level_index + draw`, `level_index` = 0, 1, 2 for LOW, MED, HIGH, draws 0-31). Within a (level, draw) all three conditions see the same graph, split and seed, so differences are paired.

**Conditions and protocol.** Exactly the metric-first study's: `tnbbeta`, `vmf_init`, `power_spherical_init` (kappa started at `DIM = 16` and trained; these are the "tuned/init comparators"), `DIM = 16`, 500 epochs, `GraphVAEConfig(decoder_bias=True)`, learning rates = the pilot's tuned rates for `scale_free` (`tnbbeta` 0.01, `vmf_init` 0.03, `power_spherical_init` 0.003; read from `graph_search/pilot/tuned_lr.json`), `SAMPLES = 32` posterior draws for every predictive metric, best-validation state as in `run_once`. Implemented as a new stage `density` of `apps/synthetic/graph_search.py` (additive: `SEED_BASE`, `EXTENDED_STAGES`; no change to any existing stage). The vMF runs use the exact sampler (default). 3 levels x 32 draws x 3 conditions = **288 runs**.

**Metrics (stored per run by the unchanged `evaluate`/`extended_metrics`).** `truth_kl` (KL of the 32-sample posterior-predictive edge probability to `balanced_truth` of the true probabilities over non-training pairs `held`), `ece`, `sampled_log_loss`, `sampled_auc`, `centre_auc`. Higher-is-better: `sampled_auc`, `centre_auc`; lower-is-better: the others.

**Paired difference and sign convention (identical for every metric).** `a = comparator - TNBBeta` for lower-is-better, `a = TNBBeta - comparator` for higher-is-better; **`a > 0` = TNBBeta better** (up in the figure). The comparator for a (level, metric) is the one of {`vmf_init`, `power_spherical_init`} with the better *level-mean value of that metric over the 32 draws*, selected from the two comparators alone (never looking at TNBBeta). Sensitivity (reported, not plotted): each comparator separately, and the per-draw-min version (advantage versus whichever comparator is better in that draw; conservative).

## Analysis (pre-specified)

- **Bars.** Per (level, metric): standardised paired effect `dz = mean(a) / sd(a)` (unit-free so five metrics share an axis) with a 95% percentile bootstrap interval (10,000 resamples of the 32 draws, seed 20261103); the raw mean difference with its own 95% bootstrap interval is in the results table and the hover text. Draws with a non-finite value in either paired run are dropped (count reported).
- **Tests (confirmatory for this figure's claims, within this experiment).** Per (level, metric): paired two-sided Wilcoxon signed-rank test of `a` against 0. **BH at q = 0.05 over the 15 tests (5 metrics x 3 levels)**; a cell is "TNBBeta better" / "TNBBeta worse" if BH-significant with that sign. Bars with a BH-significant result carry a marker. Report effect sizes with bootstrap CIs for all 15 cells whether or not significant.
- **Descriptive (NOT confirmatory; no p-value is used to support a claim).** (a) Within the density experiment, Spearman of the per-draw truth-KL advantage vs per-draw realised mean degree over the 96 draws and vs level index, per metric, with a 95% bootstrap CI over draws, plus the same Spearman computed within each level. (b) The within-family Spearman of the pooled panel (+0.462) is reproduced from the cached fresh stage (E_c vs log nominal degree, rank-centred within family), as a check that the pooled panel shows the registered number.
- **Pooled panel (fourth panel).** From the cached fresh-stage table (`graph_search/metric_first/runs_fresh.json`, `covariates_fresh.json`): per config, x = realised mean degree (mean over draws), y = median over draws of truth-KL advantage versus the less favourable of `vmf_init` / `power_spherical_init` (identical to `per_family_slope_check`), all 200 configs, coloured by family, `scale_free` points outlined. The annotation shows the pooled Spearman reproduced above.
- **Reported faithfully.** If the HIGH level shows no advantage (or a loss) on the probability metrics, or the LOW-to-HIGH ordering is not monotone, the results note and the figure say so: each bar panel carries an auto-generated line "BH-significant: better on a of 3 probability metrics, worse on b of 3; AUROC (sampled, centre) better c, worse d" computed from the tests (not hand-edited). AUROC losses are shown whatever their size.

## Figure (fixed layout; changed only through a Deviation)

One plotly figure, project `alptex` template (`tnbbeta_vae.plotting`), written at **scale 3**, legend at the bottom. Layout: 2 rows x 4 columns. Row 1, columns 1-3: one drawn `scale_free` graph per level (36 nodes, mean degree rescaled to 2 / 5 / 12 to keep the 6 : 15 : 35 ratio on a graph that cannot exceed degree 35; same `contrast = 13.0` and same drawing seed 7 for the three, so the drawings are nested draws of one weight vector; node size `6 + 4 sqrt(degree)` px, grey edges, a numpy Fruchterman-Reingold layout seeded 7, isolated nodes shown, titles "LOW / MED / HIGH density: drawn mean degree x (runs: 6 / 15 / 35)"). Row 2, columns 1-3: the five bars with intervals, order **truth KL, ECE, sampled log loss, sampled AUROC, centre AUROC**, probability-quality metrics and ranking metrics in two colours (legend entries). Column 4 (both rows): the pooled scatter, family colours in the legend. Title/subtitle with the four statements above. No re-layout, re-levelling or re-selection of the drawing seed after any result is seen.

## Deviations

All appended after the density runs and the first analysis had been read; none changes a test, level, metric or comparator rule.

The annotation's Spearman is therefore computed on `S_c` (reproduces +0.462 exactly); the y axis plots `E_c` in nats (the quantity the pre-registration describes; with `E_c` the within-family Spearman is +0.479, also reported). The first analysis run (job 2304532) used `E_c` and printed +0.479; job 2304533 is the final.
2. **Pooled y is the mean (E_c), not the median-over-draws version** of `per_family_slope_check` (the pre-registration said "identical to per_family_slope_check"; E_c is the H1 outcome, so the panel matches the registered statistic).
3. **Layout fixes after the first render (presentation only, no data change):** the first render clipped the pooled-panel title and the caption and drew the LOW graph with its components collapsed (isolated nodes pushed far out by repulsion). Fixes: more top/bottom margin, caption line breaks, log-axis tick labels, and a weak gravity (0.6) plus clipping to the frame in the force layout. The drawing seed (7), degrees and the metrics shown were not touched.
3b. Bars show dz as registered; the raw mean differences are in hover text and the results note.
