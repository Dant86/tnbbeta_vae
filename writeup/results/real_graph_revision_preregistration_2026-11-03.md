After this point the file is edited only by appending to "Deviations" at the end.
Base commit: `d5bb583` (`origin/master`, merge of PR #72), branch `real-graph-revision`. Code of this study is new (`src/tnbbeta_vae/models/real_graph_eval.py`, `apps/real_graph/`), additive to shared code.

## Purpose and framing

The paper's current real-graph figure (`features_onoff_bars`, AUC and AP, validation-selected, 5 seeds) used vMF and PowerSpherical with the library-default kappa initialisation and a free kappa. Later work (`vmf_ps_fixed_kappa_and_training_dynamics_2026-10-30.md`) showed that free kappa barely moves in 200 epochs, so part of that comparison measured kappa optimisation, and the synthetic study (`graph_search_metric_first_results_2026-11-02.md`, `scale_free_density_figure_results_2026-11-03.md`) found that TNBBeta's advantage over vMF/PowerSpherical lives on probability metrics (log loss, ECE, truth KL), grows with mean degree (pooled within-family Spearman +0.46, limited per-family significance) and does not appear on ranking metrics (AUROC, centre AUC, rank correlation), where it loses.

This study redoes the real-graph comparison with the better-matched comparators and the synthetic study's metric set, to find **honestly** where, if anywhere, TNBBeta wins on real graphs. It does NOT assume TNBBeta is better, and every null and loss is reported. No causal claim about the modality offset `m` is made anywhere (Stage 4 is descriptive).

## Data, models, protocol

**Datasets.** Cora (2,708 nodes, 5,278 edges, mean degree 3.90, degree CV 1.34, transitivity 0.093), Citeseer (3,327 / 4,552 / 2.74 / 1.24 / 0.130; 48 isolated nodes), Pubmed (19,717 / 44,324 / 4.50 / 1.65 / 0.054), MAG-CS (21,957 / 96,750 / 8.81 / 1.03 / 0.183), as loaded by the repository (`load_planetoid`, `load_mag_coauthor`). Each is run with **features on** (the real features) and **features off** (`identity_features`, a learned per-node embedding), as in the paper's figure.

**Families (conditions).** `tnbbeta` (free epsilon); `vmf` and `power_spherical` with `initial_kappa` = the ambient dimension and kappa **trained** (the primary comparators; no pinned-kappa arms and no library-default-initial-kappa arms in any stage; the default-initial-kappa free arms exist only as the existing Figure-5 outputs, mentioned in an appendix note); `gaussian` (reference; not part of the comparator for any primary test). All use `GraphVAEConfig(decoder_bias=True)` (as in the synthetic study; the training pairs are 1:1 so the bias is a small calibration offset, applied to every family), hidden width 32, learned temperature, uniform-sphere prior (Gaussian: N(0, I)). **Exact vMF sampler**: `VonMisesFisher` defaults to `exact_envelope=True` (verified at `src/tnbbeta_vae/distributions/von_mises_fisher.py` line 56 at the base commit); every run record stores `vmf_sampler` (`"exact_envelope"` or `"taylor"`, read from the posterior object that produced the samples) and the run aborts if a vMF run does not use the exact sampler. A test asserts this.

**Dimension.** "d" is the manifold dimension: sphere families use ambient `latent_dim = d + 1`, the Gaussian `latent_dim = d`, as in the paper's sweep.

**Edge split.** `split_edges` (5% validation, 10% test, the remainder is the training graph the encoder sees; an equal number of uniformly random non-edges of the graph being split for each of validation and test, disjoint). Seed `s` determines the split and the initialisation stream and is shared by all conditions (paired by seed).

**Seeds.** Final runs: 10 seeds, 0-9. Tuning runs: seeds 100-102 (different splits and initialisations from every final run).

**Training.** Adam, full-batch, epochs = the repository defaults (Cora 200, Citeseer 200, Pubmed 400, MAG-CS 200), one random negative per training edge per step (unchanged `GraphVAE.training_step`). The state is selected **per run by the best validation sampled log loss** (16 posterior samples, seeded, evaluated every epoch under a forked RNG), identically for every family. The state's test metrics are then computed once with 32 posterior samples.

**Hyperparameters (validation only, equal-handed).** For every (dataset, features, family) the same grid: learning rate in {0.003, 0.01, 0.03} x dropout in {0.0, 0.4} x d in {16, 32} = 12 configurations, each run on the 3 tuning seeds; the configuration with the lowest mean validation sampled log loss over the tuning seeds is frozen and used by every final run of that cell (all stages, including thinning, community and pinning runs; the thinned graphs and the pinned-m runs reuse the full-density free configuration of the same family, which is a documented limitation: thinning changes the optimal learning rate, equally for all families). Note that the paper's Figure-5 grid ({0.01, 0.005, 0.001} x {0, 0.2, 0.4} x {8, 16, 32, 64}, validation AUC) is a different grid and criterion; I do not reuse its selections because the new comparators (kappa initialised at d) and the new selection criterion (validation log loss) change the optimum. d = 8 and 64 are left out for cost; vMF is therefore not tuned over the full dimension range of the paper (the earlier note that vMF did better at its own dimension is respected by tuning d per family, not fixing it). With dropout and identity features, dropout acts on the hidden layer only (the first layer receives sparse identity features; `GraphVAE` skips it there), which is the repository's existing behaviour.

## Metrics

All on the **test pairs**: the held-out positives and an equal number of random non-edges, as in the synthetic study (`synthetic_graph_experiment_methods_2026-11-03.md`).

* **PRIMARY: sampled test log loss.** `p_hat_ij` = mean over 32 joint posterior samples of `sigmoid(temperature * z_i . z_j + bias)` (Gaussian: `z_i . z_j + bias`), `log loss = mean(-y log p_hat - (1-y) log(1 - p_hat))`, `p_hat` clamped to [1e-6, 1 - 1e-6].
* Secondary: sampled AUROC (of `p_hat`), centre AUROC (posterior centres), average precision (of `p_hat`), 10-bin ECE of `p_hat`. Validation versions are stored.
* **Truth KL is not available on real graphs** (there is no true probability matrix). The real-data analogue is the paired log-loss difference: for a fixed test pair with Bayes-optimal probability `q` of being a positive, `E[log loss of p_hat] = H(q) + KL(q || p_hat)`, so the difference of two models' log losses on the same pairs equals the difference of their KLs to the truth in expectation, the entropy term cancelling. The test pairs' labels are one realisation, so the realised paired difference carries label noise of order `sd / sqrt(number of pairs)` (about 0.003-0.005 nats for the test sets here), much smaller than the between-seed variation that the tests below are based on. Caveat: the "truth" here is the balanced-sampling truth (positives versus uniformly random pairs), the same convention as the synthetic `balanced_truth`, and a real graph is not generated by an edge probability matrix, so the difference is "excess log loss on these pairs", not a distance to a known generator.
* No dense n x n matrix is built for any dataset: pair scores are computed directly from node samples gathered at the pair indices.

## Statistical design (pre-specified)

Sign convention for every metric: advantage `a = comparator - TNBBeta` for lower-is-better metrics (log loss, ECE), `a = TNBBeta - comparator` for higher-is-better (AUROC, AP); **`a > 0` means TNBBeta is better**. The **primary comparator** of a (cell, metric) is the better, by the cell's mean over the 10 seeds of that metric, of `vmf` and `power_spherical`, chosen from those two alone (never looking at TNBBeta); this is conservative for TNBBeta. Each comparator separately and the Gaussian are reported in tables as descriptive (effect size, bootstrap CI, unadjusted p).

* **Paired p-values:** two-sided exact sign-flip (paired permutation) test on the 10 per-seed differences: the statistic is the mean difference and all 2^10 = 1024 sign patterns are enumerated (checked against an independent enumeration in the tests). Effect sizes are the mean difference with a 95% percentile bootstrap interval over seeds (10,000 resamples, generator seed 20261104).
* **P1 (primary, confirmatory): sampled test log loss, 8 cells** (4 datasets x features on/off), TNBBeta against the primary comparator. Holm over the 8 two-sided tests at alpha = 0.05 defines "significant". **Confirmed win / confirmed loss** additionally require a 0.05-nat margin: exact one-sided sign-flip tests of `mean(a - 0.05) > 0` (win) and `mean(-a - 0.05) > 0` (loss), Holm over these 16 one-sided tests. A cell that is significant without the margin is reported as "significant, below margin".
* **P2 (secondary): sampled AUROC, centre AUROC, AP, ECE, 8 cells each**, same test and comparator rule, Benjamini-Hochberg at q = 0.05 over the 32 tests. AUROC losses are shown whatever their size.
* **Stage 2 (degree buckets), mostly descriptive.** Each test pair is assigned to the bucket of **the lower of its two endpoints' training-graph degrees**: bins {0-1, 2-3, 4-7, 8-15, 16+} (training degree, i.e. degree in the graph the encoder sees; training degree 0 nodes exist). Within a (cell, seed, bucket) the label-balanced log-loss advantage is `(mean of a over positive pairs + mean of a over negative pairs) / 2` (label-balanced because positives are degree-biased and negatives are not; per-pair `a` = comparator log loss minus TNBBeta log loss of that pair; buckets need at least 20 pairs of each label to be reported; AUROC advantages per bucket need both labels with at least 20 pairs each). Reported per bucket: mean over seeds, seed-level bootstrap CI (the honest interval) and an edge-level bootstrap CI (resampling pairs pooled over seeds; **anti-conservative** because pairs share endpoints, shown only for comparison with the seed-level interval). The only tested quantity: the **degree-gradient contrast** `G = advantage(min degree >= 4) - advantage(min degree <= 3)` per seed, two-sided sign-flip, BH over the 8 cells (log loss, and separately AUROC; two BH families).
* **Stage 3 (density; the primary causal manipulation): edge thinning.** Before the train/val/test split, delete a uniformly random fraction of the edges so that **0.7, 0.5, 0.3** of them are retained (1.0 is Stage 1; nodes, features and graph size fixed; the thinning is seeded by the run seed, so all families of a seed see the same thinned graph and split; the validation/test negatives are non-edges of the thinned graph; thinned-away edges are simply absent). For each (dataset, level, seed) the realised mean degree, degree CV and transitivity of the thinned graph are recorded. Outcome per (dataset, features, level): the log-loss advantage over that cell's primary comparator (chosen by the cell mean at that level). Statistic per (dataset, features): Spearman correlation between the 40 (level, seed) advantages and the 40 realised mean degrees; the combined statistic is the mean of the four datasets' Spearmans. Test: one-sided (advantage increases with density) permutation test that permutes the four levels' advantages within each (dataset, seed) block (so seed effects are preserved), 100,000 Monte Carlo permutations, features on and off separately, Holm over the two. **Four dataset blocks: the test is weak by construction and is descriptive in spirit**; per-dataset Spearmans and OLS slopes (advantage versus log realised mean degree, seed-bootstrap CI) are reported, and the same analysis is repeated on AUROC (expected not to increase). Each dataset's thinned graph changes density, but also the number of isolated nodes and the clustering; all are reported per level.
* **Stage 3b (natural density range, secondary, descriptive).** Louvain communities (networkx `louvain_communities`, resolution 1.0, seed 0) of MAG-CS and Pubmed; eligible are communities with 300-1200 nodes; their induced subgraphs (features restricted to them) are the graphs. Selection rule (no outcome used): sort eligible communities by induced mean degree and take up to 12 at evenly spaced ranks. 5 seeds, all four families, features on and off, hyperparameters of the parent dataset's frozen cell. The size-matching is by the 300-1200 window (not exact); the outcome is the log-loss advantage over the primary comparator; reported against mean degree, node count, clustering and degree CV with Spearman correlations (descriptive; the confounds are the point of reporting them).
* **Stage 4 (shape and mechanism), DESCRIPTIVE ONLY.** On the free TNBBeta runs of Stage 1: the second-mode mass (per node, the lesser-hemisphere share of 64 samples about the node's mean direction, as `apps.synthetic.graph_families.second_mode_mass`), the fraction of nodes with `m = epsilon - (latent_dim - 1)/2 < 0`, the per-run Spearman of `m` and of second-mode mass with training degree (mean over seeds), and the node-level relation of these to the per-bucket advantage. Then the **m-pinning dose-response**: `fixed_epsilon` via `heads.epsilon_from_m` with `m = f * (latent_dim - 1) / 2`, `f` in {-0.6, -0.2, 0, 0.5, 1} plus the free runs, all four datasets, features on/off, 10 seeds, the free configuration's hyperparameters; log loss, ECE, AUROC, second-mode mass per cell. **No causal claim about `m` is made; no test is run; pinning epsilon also limits how concentrated a posterior can be (it is not a pure bimodality switch).** The results note presents the numbers and the figure only.

## PREDICTIONS (written before any run)

1. **Features on:** the four families are close on AUROC (all within about 1.5 points in each dataset; the Oct-9 note had all within 1.5 points except MAG-CS TNBBeta at -1.3 and Citeseer Gaussian at -2.9). Log-loss differences between TNBBeta and the primary comparator are small, `|mean a| < 0.02` nats, in at least 3 of the 4 features-on cells; no features-on cell is a confirmed win. MAG-CS features-on: TNBBeta is behind on AUROC (prediction: sampled AUROC advantage < 0, repeating the Oct-9 -1.3 point gap) while its log loss/ECE advantage is >= 0.
2. **Features off:** clearer separation than features on. The Oct-9 gaps between TNBBeta and vMF/PS (5-8 AUC points on Cora, 3-4 on Citeseer, 5-8 on MAG-CS) are partly a kappa-optimisation artifact: with kappa initialised at d, the vMF/PS AUROC gap to TNBBeta shrinks to under 2 points in at least 2 of the 4 datasets. The Gaussian reference stays at or above TNBBeta on AUROC in at least 3 of 4 features-off cells. TNBBeta's log-loss advantage over the primary comparator is positive in at least 5 of the 8 cells and Holm-significant in at least 2 of 8 (at least one of them above the 0.05-nat margin).
3. **Density:** the log-loss/ECE advantage is larger on the denser MAG-CS (mean degree 8.8) than on Cora and Citeseer (3.9 and 2.7); on Cora and Citeseer features-on, a tie or TNBBeta behind (no confirmed win on either). Under edge thinning the log-loss advantage falls as the graph is thinned: the within-dataset Spearman is positive in at least 3 of 4 datasets for features on and for features off, and the combined statistic is positive, while the AUROC advantage is not positively related to density (combined Spearman <= 0.1).
4. **Degree buckets:** the log-loss advantage is non-negative and larger in the buckets with min degree >= 4 than in the buckets with min degree <= 1 (low-degree pairs are where a sample-averaged predictive has least to work with); the AUROC advantage is roughly uniform across buckets, as the Oct-30 note found (G on AUROC not BH-significant in any cell).
5. **Shape:** free TNBBeta lands at `m < 0` for more than half of the nodes in most of the 8 cells, with a second-mode mass below 0.02 (one cap, as on every synthetic family); per-run Spearman of `m` with training degree positive in most cells (the paper's SBM figure). Dose-response: no confident prediction; weak expectation that pinned unimodal runs (f = 1) are within 0.02 nats of the free runs on log loss in at least 6 of 8 cells (the Oct-30 finding).

**What counts as a miss.** Prediction 1 is missed if any features-on cell is a confirmed win or loss on log loss, or if MAG-CS features-on TNBBeta is not behind on AUROC. Prediction 2 is missed if the vMF/PS AUROC gap stays at 2 points or more in 3 or 4 datasets, if the Gaussian is above TNBBeta on AUROC in fewer than 3 cells, or if fewer than 5 cells show a positive log-loss advantage or fewer than 2 are Holm-significant. Prediction 3 is missed if the log-loss advantage on MAG-CS is not larger than both Cora's and Citeseer's (features on and off, each), if either Cora or Citeseer features-on is a confirmed win, or if fewer than 3 datasets have a positive Spearman in either features setting, or if the combined AUROC Spearman exceeds 0.1. Prediction 4 is missed if the log-loss advantage at min degree <= 1 exceeds that at min degree >= 4 in more than 4 of 8 cells, or if any cell's AUROC gradient G is BH-significant. Prediction 5 is missed if fewer than 5 of 8 cells have more than half of the nodes at `m < 0`, if the mean second-mode mass in any cell exceeds 0.05, or if the m-degree Spearman is non-positive in more than 3 cells.

## Deviations

All appended after the analysis was read; none changes a test, comparator rule or metric.

1. **Stage 2 undefined cells.** Buckets and the degree-gradient contrast G need at least 20 positive and 20 negative pairs; in Citeseer (on and off) the group "min degree >= 4" has fewer than 20 negatives, so G is undefined there and BH for G runs over the 6 defined cells, not 8. Buckets above degree 7 are unreported in Cora and Citeseer for the same reason.
2. **Stage 3b size.** Only 8 MAG-CS communities fall in the 300-1200 node window (rule: up to 12), so all 8 were used; Pubmed used 12 of 14 eligible.
3. **Thinning tests.** The permutation test was run for AUROC advantage as well as log loss (registered as "repeated"); Holm is over the two features settings within each metric.
4. **Seed pairing for thinning.** The thinning seed equals the run seed (as registered); the realised mean degree in the covariate is that of the thinned graph before the edge split.
5. **Implementation notes.** `networkx` (an indirect dependency via torch, not declared in `pyproject.toml`) is imported lazily for Louvain. The vMF-sampler assertion is also checked every epoch during training. Tuning array tasks 3-5 were cancelled while pending and resubmitted with smaller resource requests (same manifest, finished runs are skipped); node k003 (broken CUDA) was excluded. Figure legends were moved lower after the first render (presentation only).
6. **Not done.** A validation-AUC selection sensitivity analysis and a wider hyperparameter grid (grid edges are frequently selected) were not run; the results note states this.
